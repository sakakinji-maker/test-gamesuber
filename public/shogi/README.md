# 쇼기 연습 대국

- 튜토리얼: `/shogi/` (4개 난이도 × 3문제)
- 컴퓨터와 연습: `/shogi/practice.html`
- 로컬 실행: 저장소 루트에서 `npm install` 후 `npm start`, `http://localhost:3000/shogi/` 접속
- 테스트: 저장소 루트에서 `npm test`

## 파일 구성

`engine.js`는 DOM과 분리한 규칙·합법 수 생성·상태 전이·AI 엔진입니다.
`ai-worker.js`가 AI와 힌트를 계산하고 `practice.js`가 화면, 차례, 기보, 저장을 담당합니다.
컴퓨터 계산은 최대 약 850ms의 반복 심화 탐색이며, 계산 작업을 취소할 때 워커와 요청 번호를 무효화합니다.

왕초보는 임의의 합법 수, 초보는 한 수 평가, 중급은 최대 두 수, 고급은 최대 세 수를 탐색합니다.
제한 시간 안에 완료한 깊이의 결과를 사용하므로 기기에 따라 실제 탐색 깊이는 다릅니다. 공인 급수나 전문 쇼기 엔진 수준은 아닙니다.

## 구현 범위

- 평수 초기 배치, 선후공, 8종 말과 6종 승격 말
- 승격/불성 선택, 보병·향차·계마의 강제 승격
- 포획 시 승격 해제, 말받침, 재투입
- 왕수 방치 방지, 왕의 위험 칸 이동 방지, 왕을 직접 포획하지 않고 외통으로 종료
- 이보, 마지막 줄 보병·향차 투입, 마지막 두 줄 계마 투입, 보병 투입 즉시 외통 방지
- 외통 판정 시 왕 이동뿐 아니라 다른 말의 포획·차단·말받침 투입도 고려
- 동일한 판·말받침·차례 네 번 반복 시 무승부, 연속 왕수 반복은 공격 측 패배
- 한 차례 무르기, 추천 수, 새 대국/기권 확인, 기보
- localStorage 자동 저장과 합법 수 재생을 통한 복원
- 저장 차단, 손상된 저장 데이터, 워커 오류/지연에 대한 복구

입옥 선언승과 대국 시계는 미지원입니다. 학습용으로 600수 이후 추가 진행을 제한합니다.
기보는 이 기기에만 저장되며 계정 간 동기화 기능은 없습니다. 새 대국 시 이전 대국 저장을 대체합니다.

규칙 참고: [일본쇼기연맹 규칙 FAQ](https://www.shogi.or.jp/faq/rules/).

## 검증

`tests/shogi-practice.test.js`에서 규칙과 AI, 120수 재현 가능한 무작위 대국을 검사합니다.
`tests/shogi-practice-ui.test.js`에서 DOM 이벤트를 모사해 차례 교대·승격·투입·무르기·복원·취소된 AI 응답·오류 복구를 검사합니다.
DOM 모사 테스트는 실제 브라우저의 렌더링이나 모바일 레이아웃 검증을 대체하지 않습니다.
