# 한 수씩 배우는 바둑

주소: /baduk/ · 쇼기와 같은 종이·나무판 디자인을 공유합니다.

## 기능

- 5줄 예제판의 12개 입문 문제, 힌트와 완료 기록
- 컴퓨터 연습: 9 / 13 / 19줄, 흑백 선택, 상대적 난이도 4단계
- 추천 수, 한 차례 무르기, 기권, 기보, 자동 저장과 합법 수 재생 복원
- 별도 /baduk Socket.IO 네임스페이스의 실시간 2인 대국
- 공개 대기방, 코드/초대 링크, 방장 시작, 90초 재접속, 양쪽 동의 재대국
- 키보드 방향키/Enter, 반응형 화면, 19줄판은 작은 화면에서 가로 스크롤

## 규칙 선택

학습용 면적식 바둑입니다. 흑 선착, 자충수 금지, 위치적 슈퍼코(이전 판 재현 금지), 백 덤 6.5점입니다.
판 위의 살아 있는 돌 + 한 색으로 둘러싸인 빈자리로 계산합니다. 잡은 돌은 기록용이며 점수에 중복 가산하지 않습니다.
두 번 연속 패스하면 사석 확인 단계로 들어갑니다. 돌을 누르면 연결된 무리 전체의 사석 표시를 전환합니다.
혼자 연습할 때는 학습자가 사석을 판단하며 AI의 자동 생사 판정은 없습니다.
온라인에서는 사석 변경 때마다 동의를 초기화하고 두 사람 모두 같은 상태에 동의해야 종료됩니다.
다툼이 있으면 누구나 재개를 요청하여 직접 잡을 수 있습니다. 재개 시 차례와 반복 금지 이력은 유지합니다.
서버 부하 방지를 위해 온라인 4,000수부터 착수 후 계가 단계로 전환합니다.

공식 한국·일본식 집 계산/대회 규정 전체와 같지 않습니다.
접바둑, 공인 급수, 제한 시간, 전문 AI, 사석 자동 판정은 미지원입니다.
AI는 돌 잡기·활로·단수·눈 보호를 고려하는 휴리스틱이며 난이도 이름은 공인 기력을 뜻하지 않습니다.
기본 개념 참고: [영국바둑협회](https://www.britgo.org/intro/intro2.html).
계가 방식 차이 참고: [미국바둑협회](https://www.usgo.org/content.aspx?page_id=22&club_id=454497&module_id=563542).
이 구현은 AGA 규칙 전체가 아니며 패스 때 포로를 전달하는 방식도 사용하지 않습니다.

## 저장 및 운영

연습 기보는 localStorage의 baduk_practice_v1, 수업 완료는 baduk_lessons_v1에만 저장합니다.
온라인 복귀 토큰은 sessionStorage의 baduk_online_v1에 저장하며 상대와 공유하지 않습니다.
방과 온라인 기보는 단일 프로세스 메모리이므로 서버 재시작/배포 시 초기화됩니다. 멀티 인스턴스 공유는 미지원입니다.
기존 쇼기·원카드의 규칙 및 저장 키를 변경하지 않습니다.

실제 두 Socket.IO 클라이언트의 대국·계가 동의·재접속·패·퇴장 검사.
