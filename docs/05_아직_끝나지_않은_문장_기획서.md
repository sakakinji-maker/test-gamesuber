# 아직 끝나지 않은 문장 — 기획서 v1

## 1. 방향
- 장르: 1인용 일상 미스터리·회상형 스토리 게임.
- 목표: 범인을 처벌하는 이야기가 아니라, 같은 추억을 다르게 기억한 이유를 알아낸다.
- 정서: 밝았던 과거, 작은 모순, 뒤늦은 이해, 돌이킬 수 없는 관계.
- 기존 작품의 인물·사건은 사용하지 않는 독립 창작.
- 첫 버전 예상 분량: 10~15분. 4장, 단서 12개, 추리 4개, 단일 배드 엔딩.
- 게임 제목 및 작품집 제목은 가제. 등장인물 이름은 미정.

## 2. 시작
졸업한 지 8년 후, 주인공이 책장을 정리하다 고등학교 문예부 공동 작품집 《여름의 여백》을 발견한다. 즐거웠던 동아리 활동을 떠올리던 중 면지에서 다음 문장을 발견한다.

> 우리가 만들어 나간 이야기는 여기 있지만 너가 만들었던 이야기는 아직 진행중이겠지

누가 언제 누구에게 썼는지, 그리고 어떤 이야기를 뜻하는지 조사한다.

## 3. 인물 — 총 5명
|인물|당시 역할|현재 드러나는 문제|
|---|---|---|
|나|원고 참여, 마지막 소설의 결말 수정|좋은 의도와 행복한 기억을 사실 전체라고 생각함|
|부장|일정·제작 관리|다수의 편의를 우선해 한 명의 참여를 놓침|
|편집 담당|교정과 원고 취합|명시적인 부탁보다 마감을 먼저 챙김|
|그림 담당|표지·삽화|초기 결말과 졸업식의 기록을 기억함|
|마지막 부원|자신의 경험을 섞은 소설 작성|설명할 힘을 잃고 관계를 떠남|

## 4. 책 속 소설
빈 방에서 친구들을 기다리는 인물의 이야기. 초고에서는 아무도 오지 않는다. 작가는 실제 경험이 섞였음을 메일로 알리고 결말을 유지해 달라고 부탁한다. 주인공은 공동 작품집의 밝은 마무리를 위해 친구들이 찾아오는 결말을 제안한다. 작가는 마감과 분위기에 밀려 동의한다. 인쇄본의 마지막 문장은 “우리는 그 뒤로도 오래도록 함께했다.”

## 5. 장별 단서와 추리 — 이하 스포일러
1. 책장 아래의 여름: 잉크 위 필름, 부장 증언, 졸업 사진을 비교해 글의 작성 시점을 졸업식 전으로 좁힌다. 시점만으로 작성자를 단정하지 않는다.
2. 다섯 번째 의자: 인쇄본, 교정 기록, 초기 삽화를 비교해 주인공이 결말을 변경했음을 확인한다.
3. 그렇게 해: 일정표, 원고 메일, 편집 담당 증언으로 묵살된 요청을 확인한다. 표정만으로 심리를 확정하지 않는다.
4. 문장의 수신인: 목격 증언, 당사자의 확인, 주인공의 졸업 인사를 연결해 문장의 의미를 확인한다. 당사자의 연락 동의를 거쳐 사과를 보낸다.

## 6. 엔딩
부원은 살아 있으며 이미 자신의 삶을 살아간다. 답장에는 즐거웠던 기억도 인정하지만 과거를 다시 이야기하거나 만나고 싶지는 않다는 의사가 담긴다. 주인공이 진실을 알아내도 관계는 회복되지 않는다. 마지막에 인쇄본의 행복한 결말과 다섯 사람의 사진을 다시 본다.

배드 엔딩은 잘못 고른 선택에 대한 처벌이 아니다. 추리 성공과 관계 회복은 다르다는 결말이다. 마지막 세 가지 편지 선택은 주인공 독백만 바꾸고 상대의 의사는 바꾸지 않는다. 게임 내에서도 이를 미리 고지한다.

## 7. 게임 규칙
- 장의 본문 읽기 → 단서 3개 조사 → 선택지 추리 → 해설 → 다음 장.
- 단서 세 개를 모두 보기 전에는 추리 버튼 잠금.
- 오답은 벌점 없이 힌트 제공. 단서를 다시 볼 수 있다.
- 수첩에는 발견한 단서만 누적. 미래 단서는 공개하지 않는다.
- 전투·시간 제한·수집 노가다 없음.
- 현재/과거 장면은 텍스트로 구성. 보이스·캐릭터 일러스트·자유 이동은 첫 버전 범위 밖.

## 8. UI·접근성·저장
짙은 청록 배경, 종이색 본문, 금색 강조. 책 표지는 CSS로 구성한다. 모바일에서는 세로 읽기. 모든 행동은 버튼이며 키보드로 접근 가능하다. 자동 저장은 브라우저 localStorage에 기록한다. 저장 차단 환경에서도 게임은 진행할 수 있다. 처음부터 버튼은 확인 후 진행을 지운다.

## 9. 배포
- 기존 Node 서버의 /unfinished/ 경로.
- 게임 홈페이지 목록 및 검색에 추가.
- GitHub main 푸시 후 Render 자동 배포.
- 별도 회원가입, 과금, 외부 API 없음.

## 10. 검증 및 후속 범위
검증: 문법, 모든 장 정답/오답, 단서 잠금, 수첩, 이어하기, 저장 오류 대응, 엔딩 3개 독백, 공개 파일 응답.
추가 후보: 회상 속 대화 분기, 실제 책 페이지 비교 UI, 인물 이름 확정, 배경 음악, 장면 일러스트. 첫 버전의 추리는 선택형이며 자유로운 증거 조합 시스템은 아직 없다.
