# 메이플스토리 월드 게임 QA 사례

작성자: 정회성 · 정리일: 2026-10-22 · 테스트 실시일/빌드/월드명/기기 환경: 미기록

메이플스토리 월드 게임을 개발하며 플레이 중 발견한 전투, 입력, 성장, 진행 및 UI 문제를 기록한 QA 사례입니다. 사용자 제공 메모 53개에서 반복된 원문 13~25번 13개를 제거해 **고유 항목 40개**로 정리했습니다. 개선 제안과 명세 확인 항목도 포함되어 있으며, 40개 모두 확정된 버그라는 의미는 아닙니다.

## 역할과 기록 범위

- 사용자 수행: 개발 중 직접 플레이하며 문제 현상과 개선 의견 기록.
- 이번 정리: 중복 제거, ID 부여, 유형 분류, 우선순위 제안, 기대 결과 및 재검증 절차 작성.
- 아래 절차는 메모에서 구성한 **재검증용 초안**입니다. 실제 재현 성공, 원인 분석, 코드 수정 또는 수정 후 통과 실적을 의미하지 않습니다.
- 원문 1~14번 주변의 취소선·물결표는 의미와 적용 범위가 불명확하여 이력 표시만 보존했습니다. 전 항목 상태는 ‘재검증 필요’이며 해결 건수·해결률은 산출하지 않습니다.
- 23번과 25번, 9번과 26번은 관련 증상이지만 서로 다른 관찰을 포함하므로 별도 유지했습니다. 원인이 같다고 확정하지 않았습니다.
- 스크린샷·영상·로그·발생 빈도·담당자·확정 명세는 미제공입니다. 아래 기대 결과와 우선순위는 검토용입니다.

## 우선순위 기준

- P1: 전투·진행 차단 또는 능력치·재화 신뢰성에 영향 가능. 먼저 재현 및 명세 확인.
- P2: 조작·화면·스킬 정보 사용에 영향. 주요 흐름과 함께 검증.
- P3: 사용 편의·가독성·연출 개선. 정책과 개선 효과 검토.

## 집중 분석 사례

### 능력치 일관성 — MSW-023 / MSW-025

선택창 이동 전 920 → 왕복 후 520 → 전투맵 진입 후 620이라는 구체적 관찰을 기록했습니다. 능력치 종류, 장비, 버프 및 맵 보정 조건을 고정하고 각 전환 시점의 값을 비교하는 재검증을 제안합니다. 상태 갱신·저장·합산 경로는 조사 후보이며 확인된 원인은 아닙니다.

### 강화 반영 — MSW-024

강화 성공 여부, 장비 상세 값, 장착 후 캐릭터 값을 분리해 확인합니다. UI 표시만 누락되는지 실제 능력치 계산도 누락되는지 판별하도록 절차를 구성했습니다.

### 사용권 소비 — MSW-040

소멸 제보를 바로 재화 손실 버그로 확정하지 않고 입장 시 차감 정책부터 확인합니다. 입장 직후, 중도 퇴장, 완료 후 수량을 비교해야 정상 소비와 오류를 구분할 수 있습니다.

## 상세 기록

### MSW-001 · 타격 불가 중 몬스터 생성·이동 지속

- 원문 번호: 1
- 영역 / 유형 / 제안 우선순위: 전투 / 확인 필요 / P1
- 상태: 재검증 필요
- 원문 표시: 취소선·물결표 표시 있음: 완료 여부 확인 필요
- 관찰: 히트는 안 되지만 몬스터가 계속 생성되고 움직인다는 메모. 게임 전체 정지인지 전투 입력·판정 문제인지 불명확.
- 기대 결과(검토안): 정상 전투 상태에서는 공격 입력과 타격 판정이 함께 동작해야 한다.
- 재검증 절차(초안): 전투 진입 → 공격 입력 → 타격·몬스터 생성·이동 상태를 각각 기록한다.
