## 화면 구현
- 현재 대화 시 3열×2행 캐릭터 아틀라스에서 해당 초상화 표시. 마지막 칸은 작품집 이미지.
- 배경 4종: 서진의 방, 카페, 학교 복도, 자료 열람실.
- 회상 대화는 환경과 화자명으로 표현. 현재 성인 초상화를 고교 시절 모습으로 재사용하지 않음.
- 기존 174장면의 순서·엔딩·저장 키 유지. v2 진행 데이터로 그대로 이어 읽을 수 있음.
- 원본 대본의 역할 식별자를 visuals.js에서 이름으로 변환. 실제 표시 대본·수첩·문서에도 이름 적용.
- 실제 사진이나 실존 인물이 아닌 생성 일러스트. 보이스·표정 애니메이션·청소년 초상화는 이번 범위 밖.
